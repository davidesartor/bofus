RBF mixture prior

Samples of RBFMixture.sample: f(x) = Σi ai Πj exp(−(xj − xij)² / 2lij) on [−1, 1]d. Each log lij = log β + σ ε with σ = σ0 / √d, ε ~ N(0, 1), β solving (m + 1)·E[φ²] = coverage, so atoms fill that fraction of the box at any d; amplitudes are N(0, 1/(m·E[φ²])) at the final β, so the box mean of Var f is 1 before clipping. l and a are then clipped to their ranges. The l prior switch compares l = β G with G ~ Gamma(αeff + d/2) and log-uniform l on log β ± W0 / (2√d), β solved the same way, and uniform l with median at the single-scale coverage l* ((m + 1)·E[φ²(l*)] = coverage) and upper bound at half the l cap, the lower bound clamped to the l range. Log-normal: log l = log β + σ ε with σ = σ0 / √d, β solved the same way. Amplitudes are normalized the same way for all five.

Exact values (variance, clipped mass) use the same 512-point quadrature as the code: log L on −log α + [−6, 6] with inverse-gamma weights (gamma: log α + [−12, 6]), β by interpolation over ±log α + [−20, 10]. Variance after clipping is m·E[a²clip]·E[φ²(lclip)], with each factor computed in closed form or by that quadrature. MC var checks it on 160 fresh draws × 64 points; with periodic on, every dimension wraps with period 2 like the kernel, while the exact values keep the line energy the code uses, so MC var shows that approximation; kurtosis E f⁴ / (E f²)² on the same points is 3 for Gaussian-like f and grows when f is flat except for rare spikes.

The l range follows scripts/run.py: an unset cap (None) becomes d, since the coverage lengthscale grows like 2d / (3 ln m); a fixed cap of 1 starves high d. Amplitudes are clipped to ±3.
